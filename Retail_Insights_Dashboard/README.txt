RETAIL PULSE - STREAMLIT DASHBOARD

Files:
- app.py: redesigned interactive dashboard with Plotly charts
- retail_data.csv: new sample retail dataset (850 orders)
- requirements.txt: Python dependencies

Run on Windows / macOS / Linux:
1. Extract this ZIP file.
2. Open a terminal in the extracted Retail_Insights_Dashboard folder.
3. Install dependencies:  pip install -r requirements.txt
4. Start dashboard:       streamlit run app.py
5. Open the local address printed by Streamlit (usually http://localhost:8501).

Dashboard features: region/category/customer filters, date range, revenue and profit KPIs,
monthly trend, category mix, top products, regional profit, segment comparison,
discount analysis, filtered table and CSV download.

The dataset is newly generated sample data for demonstration; values are not real company records.
